# odin-calculator
Simple calculator serving as the milestone project of the **Fundamentals** course from the [Odin Project](https://www.theodinproject.com/lessons/foundations-calculator).

Expressions are parsed using a [recursive descent parser](https://en.wikipedia.org/wiki/Recursive_descent_parser).

Supported operations include : 
- Addition
- Subtraction
- Multiplication
- Division
- Modulo
- Exponentiation
- Square root
- Percentage

The calculator also support parenthesis and implicit multiplications.

Styling copied from the [GNOME calculator](https://apps.gnome.org/en/Calculator/).
